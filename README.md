A faster drop-in for make.fun's csv-reader 1.0.0: a single-pass, slice-based CSV reader that returns exactly the same {columns, rows, errors} answers on every case, with much lower CPU time.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
